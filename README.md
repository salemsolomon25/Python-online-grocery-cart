# Python-online-grocery-cart
Python online grocery shopping cart application featuring inventory management, cart tracking, checkout processing, and menu driven user interaction.

## Features

- Browse grocery categories
- Add items to a shopping cart
- Track quantities and item totals
- Calculate cart totals
- Checkout functionality
- Inventory management using dictionaries
- Input validation and menu navigation

## Technologies Used

- Python

## Concepts Demonstrated

- Functions
- Dictionaries
- Loops
- Conditional statements
- User input validation
- Data structures
- Program modularization

## Categories Included

- Produce
- Meat & Poultry
- Rice & Pasta
- Bakery
- Drinks

## What I Learned

This project helped me practice building a larger Python application by organizing inventory data, creating reusable functions, managing user interactions, and implementing shopping cart logic.
